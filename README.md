# NeXora Brilliance

Build a unique, modern, fast professional portfolio website for NeXora Marketing Agency, inspired by the visual quality and portfolio structure of prism-me.com/portfolio but not a copy. Use the attached logo image in the sticky header and footer; derive a sleek dark navy and gold visual system from it. Parse the attached NeXora Portfolio PDF as the source of truth for all written content, services, stats, projects, and extract/reuse relevant PDF imagery for portfolio cards. Use the uploaded logo image for branding. Include: responsive sticky navbar with smooth scrolling, high-impact hero with CTA, services hover-card grid, interactive filterable portfolio grid with project detail modal, about/stats section based on PDF, professional contact form and footer. Prioritize zero layout shift, optimized imagery, subtle smooth scroll animations, accessibility, and flawless mobile responsiveness. Make the website polished and complete.
